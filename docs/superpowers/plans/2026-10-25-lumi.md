# Lumi Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

> **Language:** English — the source of truth for implementation. Vietnamese reading copy: `2026-10-25-lumi.vi.md`. If the two ever disagree, this file wins. Update both together.

**Goal:** A Windows desktop app (Tauri 2) named **Lumi**. The user pastes a TikTok/Instagram/YouTube/Facebook link, the app shows direct URLs for MP4/MP3/images (plus TikTok "Original sound"), then downloads through the Save as dialog.

**Architecture:** The core is Rust (`src-tauri/src/`). It runs `yt-dlp.exe`/`gallery-dl.exe`/`ffmpeg.exe`/`deno.exe` as child processes. These binaries are downloaded into `%LOCALAPPDATA%\Lumi\bin\` on demand. The core exposes two UI-agnostic commands: `resolve(url)` and `download(url, option_id, dest)`. Downloads are owned by the Rust side and broadcast events to every window. The UI is Svelte 5 in a frameless, transparent window with the Mica effect.

**Tech Stack:** Tauri 2 (≥ 2.4), Rust stable (MSVC), tokio, reqwest (rustls), serde, `windows` crate (DPAPI), zip, sha2. Frontend: Svelte 5 + TypeScript + Vite, vitest. Plugins: `tauri-plugin-dialog`, `tauri-plugin-clipboard-manager`, `tauri-plugin-store`, `tauri-plugin-opener`.

**Spec:** `docs/superpowers/specs/2026-10-25-lumi-design.md`. Keep the "seams" needed to plug in mode B later, described in `docs/superpowers/specs/2026-10-25-lumi-browse-mode-design.md`, but do **not** build mode B.

## Global Constraints

- Windows 10/11 x64 only. NSIS installer. Installer target **under 10MB**. No code signing.
- The installer does **not** bundle yt-dlp, gallery-dl, ffmpeg or deno.
- yt-dlp and gallery-dl are downloaded on first launch. ffmpeg is downloaded when first needed (MP3 or video merging). deno is downloaded on the first YouTube link. Every download prompt shows the real size (from `Content-Length`).
- Every child process runs with `CREATE_NO_WINDOW` (`0x08000000`) and env `PYTHONUTF8=1`, `PYTHONIOENCODING=utf-8`. yt-dlp always gets `--encoding utf-8 --no-playlist --no-warnings`.
- Never show raw logs or stack traces to the user unless they click "Show details".
- Every UI string exists in both `vi` and `en`. Default follows the Windows language: `vi*` → Vietnamese, anything else → English. Changeable in Settings.
- Cookies are DPAPI-encrypted at rest (current-user scope). They are decrypted to a temp file only while a child process runs, and deleted afterwards.
- No Tauri IPC for external domains. Capabilities apply only to the `main` and `login-*` windows on the internal origin.
- App identifier: `app.lumi.desktop`. Display name: `Lumi`. Data folder: `%LOCALAPPDATA%\Lumi\` (`bin\`, `accounts\`, `webdata\accounts\`, `tmp\`).
- Event names: `lumi://job`, `lumi://tool-progress`.

## Review Focus

1. **Link variants:** short links and links with tracking parameters (`vt.tiktok.com/…`, `vm.tiktok.com/…`, `instagram.com/reel/…?igsh=…`, `youtu.be/…`, `m.youtube.com/shorts/…`, `fb.watch/…`, `m.facebook.com/…`, `web.facebook.com/share/r/…`) must map to the right site. Tested in Task 2 (`detect_site_variants`).
2. **Bad titles as file names:** titles with emoji, Vietnamese diacritics, forbidden characters `<>:"/\|?*`, newlines, empty titles, reserved names (`CON`) or 500 characters must all become a valid, non-empty Windows file name of at most 120 characters. Tested in Task 8 (`sanitize_*`).
3. **Pasting a playlist or channel link** (`youtube.com/playlist?list=…`, `youtube.com/@user`, `tiktok.com/@user`): must return a clear `playlist_not_supported` error, never hang or download hundreds of videos. Tested in Task 3 and Task 5.
4. **Tool deleted or quarantined by antivirus mid-session:** return `tool_missing` with a "Reinstall tool" button, never panic. Tested in Task 4 (`run_tool_missing_binary`).
5. **Cancelling mid-download:** the child process is killed, the job's temp folder is deleted, and no partial destination file is left behind. Tested in Task 9 (`cancel_cleans_temp_dir`).

Format grouping rules (spec §4.2–4.3):
- Standard height buckets are `[2160,1440,1080,720,480,360]`. Each real height maps to the largest bucket ≤ it; keep at most one row per bucket. Label is `"{h}p"`. `ext: "mp4"`.
- `filesize` = `filesize` or `filesize_approx` of the best video in that bucket, plus the best audio if the video has no sound. If no number is available, `None`.
- `direct_url`: prefer a combined format (both `vcodec` and `acodec` present and not `"none"`) in that bucket, with `note = None`. Otherwise use the video-only URL with `note = NoAudio`. Formats whose `protocol` contains `m3u8` or `dash` get `direct_url = None`.
- Audio (always present if there is sound): `label "MP3"`, `ext "mp3"`. `direct_url` is the best audio-only URL (`note = SourceAudio{ext}`); if none, the best combined format (`note = SourceIsVideo`).
- YouTube with `!has_deno` → `MediaInfo.limited_formats = true`.
- `_type == "playlist"`: if the site is Instagram or Facebook, each entry becomes a `MediaItem`. Otherwise (YouTube playlist/channel, TikTok profile) → `Err(PlaylistNotSupported)`.
